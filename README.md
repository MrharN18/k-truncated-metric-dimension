# k-truncated-metric-dimension

This repository contains the Python implementation of the algorithm developed
as part of my master's thesis on the $k$-truncated metric dimension of graphs.

The algorithm constructs a $k$-truncated resolving set for generalised tadpole
graphs, consisting of a cycle with pendant paths attached to arbitrary cycle
vertices.

assist with writing, debugging, and refining the code.
